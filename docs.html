Input format at a glance

Each animal should have paired columns with the same identifier before the underscore:

CTL1_Ax CTL1_My CTL2_Ax CTL2_My EXP1_Ax EXP1_My EXP2_Ax EXP2_My
Myelin value. MyeliMetric calculates fiber diameter as Ax + My. If the measured myelin thickness is a one-sided radial thickness t, the _My input should represent the full myelin contribution, i.e. 2t. Do not double a value that already represents the full contribution.

Default settings

  • Minimum axon diameter: 0.15 µm
  • Minimum myelin value: 0.03 µm
  • Fiber-diameter bins: 6

The V2 interface allows these values to be adjusted and provides a Reset to defaults control.
