Quick start

  1. Download the Windows standalone ZIP from the latest GitHub Release.
  2. Extract the ZIP to a normal folder.
  3. Open MyeliMetric.exe.
  4. Choose one save location.
  5. Load CTL data, then EXP data.
  6. Select Step 3: Analyze.
  7. Review the Control, Experimental, and Summary folders.
Windows security. Unsigned research software may trigger a Windows or institutional security prompt. Verify that the file came from the official MyeliMetric GitHub release. Do not disable system security globally.

Standalone requirements

  • 64-bit Windows
  • Write access to the selected output folder
  • Excel or CSV measurement files
