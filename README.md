# MyeliMetric-Website

Professional GitHub Pages website for **MyeliMetric-V2**.

## Intended public URL

`https://intakhar-ahmad.github.io/MyeliMetric-Website/`

## Repositories

- Website: `Intakhar-Ahmad/MyeliMetric-Website`
- Software / releases: `Intakhar-Ahmad/NeuroMyelin-G-Ratio-Analysis-Toolkit`

## Files

- `index.html` — main landing page
- `v2.html` — Version 2 improvements
- `validation.html` — validation and example output
- `docs.html` — user manual and examples
- `paper.html` — publication details and citation
- `download.html` — standalone download instructions
- `styles.css`, `script.js` — shared site styling/behavior
- `assets/` — real screenshots and result figures
- `docs/` — Word manual and V2 validation document
- `examples/` — example CTL/EXP data and example output
