# Changelog

## MyeliMetric-V2

- Added a three-step standard workflow: load CTL, load EXP, Analyze.
- Added one chosen save location with automatic Control, Experimental, and Summary folders.
- Added save-location safeguards.
- Added user-adjustable bin count with default 6.
- Added user-adjustable exclusion thresholds with defaults 0.15 µm axon and 0.03 µm myelin.
- Added CSV input to the standard workflow.
- Added an activity log, run logs, and exclusion audit information.
- Added a collapsible advanced stage-by-stage workflow.
- Added a standalone Windows distribution path for end users.
- Changed control reference binning from first-control-only to pooled control animals.
- Added organized summary output and CTL-versus-EXP comparison figures.
