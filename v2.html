What changed in MyeliMetric-V2

V2 is designed to make the published analysis easier to run, easier to distribute, and easier to audit while preserving the scientific purpose of the original tool.

Important distinction. The g-ratio definition, fiber-diameter calculation, default thresholds, descriptive statistics, and Shapiro-Wilk analysis remain aligned with the published workflow. V2 also makes one deliberate reference-binning change: pooled control animals define the diameter ranges instead of the first control animal alone.

Why these changes matter

Fewer workflow errors

A single save location and automatic subfolders make it harder to lose or mix output files.

Clearer sequence

The standard interface separates loading from analysis, so the user prepares the run before processing begins.

More flexible settings

Bins and thresholds can be adapted to the scientific question while retaining the published defaults.

Better reproducibility

Run logs and exclusion audit information document what was processed and what was excluded.
